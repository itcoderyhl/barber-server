# barber-server
基于SpringBoot3+Vue3前后端分离的美容美发管理系统，系统包含管理员、用户角色，功能如下： 管理员：首页统计（消费金额统计、会员统计）；会员管理；Tony老师管理；预约管理；订单管理；评价管理；礼品管理（礼品信息、兑换信息）；充值管理；积分变更；留言管理；公告信息；系统设置（服务分类、服务明细；会员等级；系统配置）；个人信息；密码修改。 发型师：预约管理（到店、接单、完成、取消）；订单管理；评价管理；公告信息；个人信息；密码修改。 用户：注册、登录系统；Tony老师；服务预约（预约服务）；预约管理（取消）；订单管理；评价管理；礼品管理（礼品信息、兑换信息）；充值管理；积分变更；留言管理；公告信息；个人信息；密码修改。
